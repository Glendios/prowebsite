Stuck Orders at a Fulfillment Center

        
KNAPP: Python, Oracle SQL, Bash

        
About a dozen multi-part orders a day sat unfinished, holding inventory other orders needed. Diagnosing one by hand took 15–20 minutes across several logs and database tables.

        
I wrote an order-investigation tool that shows those logs and tables together. With it, every stuck order pointed to the same host-integration defect in how multi-part orders were completed. I filed it with the trace and SQL evidence and worked with the core developers on the fix.

Dental Lab Case Intake

        
Python, OCR, SQLite, Playwright

        
Staff typed every work order into the lab's Access system by hand. The program reads each scanned slip, compares the fields with the lab's records and holds anything doubtful for a person to approve.

        
Cases from dental portals go into the same queue. When a portal emails a notification, a Playwright script signs in and downloads the case.

Agent Memory MCP Server

        
Python standard library, MCP, SQLite FTS5

        
Two coding agents on one machine can't see each other's history, and neither remembers much between sessions. This server indexes the conversation logs of both (Claude Code and Codex) and lets either search them: 128K+ messages, about 2 ms a search.

        
It uses SQLite FTS5 because what I look up is usually an exact string, like an error message or a file name.
