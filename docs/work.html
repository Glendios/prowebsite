About

I'm a software engineer at KNAPP, working on the warehouse-control platform for a Walmart e-commerce fulfillment center. Most of my code is Python and SQL. I studied computer science at UC Davis, and I speak English, Korean and Japanese.

KNAPP

2026 – now, Stockton, CA

KNAPP supplies the shuttle storage, goods-to-person picking and conveyor systems at a Walmart fulfillment center that runs around the clock and handles millions of orders a month. I joined for the site's go-live and stayed through stabilization.

I work with KNAPP's software engineers on the platform, which is C++, Oracle PL/SQL and Linux. I test new features, triage bugs in Azure DevOps, and check fixes against the live system. I also run the production releases: branch merges, builds, database migrations and the checks after deploy.

The Python and Bash tools the site team uses every day are mine to build and maintain. They cover live monitoring, log processing, equipment status, inventory reports and order investigation. The order tool is how I found a host-integration defect that left about 12 multi-part orders a day stuck holding inventory. I worked with the core developers on the fix.

When an incident is serious enough to escalate, which happens 2–3 times a day, I'm the technical contact for Walmart's site leadership. I bring in whichever team owns the problem: software, controls, mechanical or database.
