Workflow automation

Dental Lab Case Intake

A dental lab handling hundreds of active cases a month entered every case by hand from paper work orders and from external dental portals into a Microsoft Access lab manager. I built the Python system that does that entry now, with a person still checking anything the software can't read reliably.

Python OCR (local and Azure Document Intelligence) Playwright SQLite PySide6 Microsoft Access

Result

About 3 hours of entry down to about 5 minutes

Paper cases arrive as scans; digital cases arrive as email notices from portals such as 3Shape. Both now become structured records that staff confirm in a review screen before the case is created.

  • Fields extracted: patient, doctor, case ID, shade, date in, due date, material and notes, with the original scan stored alongside.
  • Digital-case intake runs end to end: Playwright signs in to each portal, pulls the case details and stages the case.
  • Used to digitize thousands of historical case records across about 10 years for long-term lookup.
Scan lands or portal notice arrives
OCR and parse fields

Staff confirm, then Access

How it works

Watched folders. The scanner writes files slowly, so intake waits until a file stops changing before reading it, instead of parsing half-written scans.

OCR with a choice of engine. A local engine handles clean printed fields; Azure Document Intelligence is available for harder pages. Either way the output goes through the same parser and validation.

Review queue. Parsed cases wait in SQLite. A PySide6 desktop screen shows the scan next to the extracted fields so staff can correct and approve in seconds.

Why a person stays in the loop

OCR reads printed fields well and handwriting badly, and a wrong shade or due date becomes a remade crown. Validation rules and duplicate warnings catch most problems, and nothing is written to the lab system until someone has confirmed it.

Operations

Errors are logged per file, failed files stay in place for a retry, and command-line tools re-run any step on demand. The app is packaged so it runs on the lab's office PCs without a Python install.
