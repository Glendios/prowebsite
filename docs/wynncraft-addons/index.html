Wynncraft Add-ons

Release 2026.10.05.3 · Minecraft 1.21.11 · Fabric · Wynntils 4.1.0

Item protection and reroll confirmation, event labels, map travel links, window sizing, party fixes, quest navigation and update notifications.

  • RAR — add to an existing profile
  • ZIP — add to an existing profile
  • Modrinth pack — create a new profile

Use your existing profile

  1. Close Minecraft and open your profile’s folder from your launcher.
  2. Extract the RAR or ZIP. Remove older copies of these add-ons from your profile’s mods folder.
  3. Drag the eight JARs from the extracted mods folder into your profile’s mods folder. Remove any older Wynnventory JAR too. Keep your existing configuration.
  4. Launch normally with Fabric API and Wynntils 4.1.0 installed.

The RAR and ZIP contain only the custom add-ons. They need Minecraft 1.21.11 and Fabric Loader 0.18.5 or newer. Other Minecraft or Wynntils versions are unsupported.

Start a new profile

Import the .mrpack in Modrinth or Prism. It includes the eight add-ons and downloads the pinned Fabric API and Wynntils versions. This is a minimal profile; it does not include the rest of another modpack.

Item-price tooltips use Wynnventory’s crowdsourced market listings. This read-only compatibility edition enables price tooltips; it does not upload observations, enable Wynnventory’s reward screens or install updates automatically. Prices are estimates, not appraisals of your exact rolls. Original Wynnventory project.

Future updates

Update Watcher checks after world entry and hourly while playing. A newer compatible release produces a clickable download notice. Use /wynnupdates to check now, or /wynnupdates off and /wynnupdates on to control automatic checks.

Updates are downloaded and copied manually with the game closed. The watcher sends no player identity or game data. The host receives normal web request metadata, including your IP address.
